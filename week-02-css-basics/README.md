# Week 2: CSS basics

Make it look good. Learn how CSS finds elements and how every element is a box.

Each day is about 60 minutes. Create a folder for the day (for example `day-01`), do the task **by typing it yourself**, write your notes, then commit.

---

## Day 8: Connect CSS and use selectors

Add a `style.css` file and link it. Style with **element**, **class** and **id** selectors. Change colours and fonts on your About Me page.

**Teach-back:** What is the difference between a class and an id? *(write the answer in your own words in `notes.md` for the day)*

## Day 9: Text and units

Practise `font-family`, `font-size`, `line-height`, `text-align`. Learn `px`, `rem` and `%`. Add a Google Font with a `<link>`.

**Teach-back:** When is `rem` better than `px`? *(write the answer in your own words in `notes.md` for the day)*

## Day 10: The box model

Learn `margin`, `padding`, `border`, `width`, `height` and `box-sizing: border-box`. Use DevTools to see the box of any element.

**Teach-back:** Draw the box model on paper and explain each layer. *(write the answer in your own words in `notes.md` for the day)*

## Day 11: Display, backgrounds and shape

Learn `display` (`block`, `inline`, `inline-block`), `background`, `border-radius` and `box-shadow`. Turn a link into a button.

**Teach-back:** Why can't you set a width on an `inline` element? *(write the answer in your own words in `notes.md` for the day)*

## Day 12: Hover, focus and transitions

Add `:hover` and `:focus` states to links, buttons and inputs. Make the changes smooth with `transition`.

**Teach-back:** Why does `:focus` matter for people using a keyboard? *(write the answer in your own words in `notes.md` for the day)*

## Day 13: Build: style your About Me

Sketch a design on paper first, then style your About Me page to match it. Keep the CSS tidy and in one file.

**Teach-back:** What did you change from your sketch, and why? *(write the answer in your own words in `notes.md` for the day)*

## Day 14: Review day

Without looking, style a plain page: colours, fonts, a button with hover. Commit and update your notes.

**Teach-back:** Which three CSS properties did you use most? *(write the answer in your own words in `notes.md` for the day)*
