# HTML & CSS Learning

I'm starting web development again from the very beginning, and writing everything by hand.
This repository is my 28-day plan for HTML and CSS: one small page a day, with notes in my own words.

> I build with AI-assisted tools, and I'm learning the fundamentals so I truly understand what I ship.

## The rules

1. **Type everything myself.** No copy-paste, and no AI writing the code.
2. **AI only to explain or to review.** For example: "explain margin and padding", or "what is wrong with my code?". Never "write it for me".
3. **One small step a day** (about 60 minutes), then a commit.
4. **Teach-back.** After each lesson, explain it in three sentences in my own words. If I can explain it, I understand it.
5. **Stuck?** Read MDN first, try for 15 minutes, then ask for an explanation (not the answer).

## Setup

- [VS Code](https://code.visualstudio.com/) with the **Live Server** extension
- [GitHub Desktop](https://desktop.github.com/) to commit and push
